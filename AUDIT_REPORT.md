# Storyboard Studio Next 0.12.0 audit

Scope: Storyboard Studio and its shared handoff compatibility. Subtitler receives its separate 0.8.1 patch; FolderExporter is unchanged. Original uploaded project/transcript/media were inspected read-only; production user folders were not modified.

## Confirmed findings and corrections

1. **Tags had two inconsistent definition paths.** The manager only edited custom definitions, while rendering used static built-ins. A shared resolved definition now merges built-in defaults and per-project appearance. Every automatic/permanent/custom tag has a pencil and pasteable symbol/color; permanent identity/deletion stays protected. Card and tag context menus reach the same manager; manual changes respect the captured selection.
2. **Working cleanup edits and archive history were mixed.** Ordinary changed-file refresh could preserve another historical cleanup version. The current working image is now accepted and its preview/dimensions/current recovery updated. Obsolete unused recovery is retired after verifying the new working/recovery bytes. Historical active references in Undo are refreshed so an unrelated Undo does not resurrect obsolete recovery metadata.
3. **Still-image imports preserved JPEG working extensions.** Still-image preparation now converts to PNG at full decoded dimensions, with alpha where present. Existing managed non-PNG stills migrate through the same adoption pipeline. External originals remain untouched; old managed JPEGs are retired only after successful publication and verification. Video and animated GIF bypass conversion. PNG conversion does not restore JPEG detail/transparency already lost or preserve every original metadata/bit-depth profile.
4. **Archive deletion was an undoable metadata operation coupled to irreversible file removal.** The destructive native purge path was removed. The action now uses OS Trash, reports partial failures, protects shared active/unassigned/reference media and scrubs discarded versions from session Undo/Redo. No irreversible fallback is used if Trash fails.
5. **Restore implicitly reattached to an old card.** Archive restore now makes a grouped Not Assigned cleanup item. The user chooses its card by dropping it. Attachment preserves inactive records/export exclusions needed to keep deliberately removed media out of discovery.
6. **A legacy inactive cleanup could lose its routing row.** Verified archive rows now repopulate the same owner's inactive relationship before move planning. An old inactive duplicate already at its archive destination can be consolidated only after registered ownership and both content fingerprints agree, and only when that destination is not active artwork. A journal stages the duplicate until metadata commits; changed bytes remain preserved. This was found by the full real-filesystem restore/rename cycle, not inferred solely from UI screenshots.
7. **Perform swapped unloaded image markup.** Next images are preloaded/decoded with a bounded cache and generation checks. The previous drawing remains until the next is ready. Expanded Perform retains its actual Play/Pause control rather than creating a second competing player.
8. **XML required audio even when the requested output did not.** Export without audio now skips recording materialization/availability checks while retaining usable existing cue boundaries. With no timings, ordered equal-duration cues are synthesized and explicitly labeled. Audio cuts and chapter markers are independent, opt-in options. Stereo cuts share exact boundaries/source intervals; markers use actual chapter/subchapter labels and skip the first exported chapter.
9. **Folder-title changes were implemented as individual file transfers.** A whole-folder rename transaction now stages registered chapter/archive directories and rebases shared path fields and path-keyed maps. Unrelated contents stay with the directory; collisions preflight before changes. A recovery journal restores an interrupted operation. A naming revision prevents a stale manifest from restoring the old layout, and Undo snapshots adopt committed path changes.
10. **Check Project ran an importer/organizer before presenting a check.** It is now observational. Save/Refresh performs controlled operations first; Supervisor checks last. Its plan uses a clone, actual file observations clear stale missing claims, audio uses the recording-identity algorithm, and manual checks inspect backup structure. An unchanged outcome does not rewrite Last check merely to advance a timestamp.

## Regression controls

The seven-card Chapter 1 fixture, reusable pair, occupied legacy archives, multiple components, cleanup removal, unchanged modification times, restore/reassign and project relocation are covered with the production Rust filesystem bridge. The bridge was updated to remove its obsolete permanent-purge call. Whole-folder rename retains unrelated files and restores interrupted installs. Trash and PNG conversion have separate failure/integrity tests. Readable user artwork is never replaced by a Supervisor guess.

This audit corrects the confirmed paths above; it is not a proof that the entire application is bug-free. See TEST_REPORT.md and PATCH_TESTING.md for actual checks and native-platform limits.
