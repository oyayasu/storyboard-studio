# Storyboard Studio workflow rules — 0.12.0

1. **Choose one main project folder.** Cmd/Ctrl+S asks you to choose/create it if none is connected. Cards are exported into separate chapter folders. Until a folder is selected, closing saves internal project progress without exporting PNG cards.
2. **Keep Studio Link with the project.** File offers Choose/Change/Locate project folder. Existing Studio Link is inspected first. Reconnect a moved/renamed folder; do not create another folder at the old location. Copy the complete project folder, including recovery files, when archiving or changing computers.
3. **Permanent identity is separate from numbering.** Reordering changes playback/display order, not card IDs, script links or cleanup ownership. Slight modify letters stay stable after deletions. Rename in order previews a whole family's renumbering; update matching CSP/PSD folder labels yourself afterward. Make regular card removes the numbering relationship and automatic Modified indicator. Reusable copies share artwork; independent modifications do not.
4. **Use any of the three cleanup entry methods.** Put correctly named files in the chapter folder; export using FolderExporter; or attach/drop files onto a card in Clean up. Different drawings may live in separate CSP files; one file per chapter is not required. FolderExporter has its own detailed instructions.
5. **The project copy is the working artwork.** External originals are left untouched. Still images use full-resolution PNG working copies (existing JPEGs can migrate on Save/Refresh); transparent pixels are retained where present. Video/animated GIF formats remain intact. Deleting/editing a former Desktop source has no effect after copying.
6. **Edit working cleanups directly when needed.** Remove backgrounds or change colors/dimensions in the project copy. Refresh/Save accepts readable edits and updates preview/current recovery. Ordinary edits do not keep a separate previous-version archive. A current recovery copy protects against a missing working file; losing both copies can still lose artwork.
7. **Drop another file to stack it.** Component index 1 is the bottom. Arrange components in Clean up, where the top row is in front. Component names are optional; indices establish order. Whole-frame references use a distinct configurable _FULL pattern and remain out of the stack. Unrelated names and OS duplicate suffixes are not guessed as another card.
8. **Active cleanup archives its rough.** Original storyboard drawings stay internally available. Rough PNGs use `Storyboard Archive/<chapter>_storyboard`. Removing cleanup in the app disconnects it, preserves the managed cleanup in its inactive archive, and returns/regenerates the rough in the main chapter folder. Missing artwork retains its identity until restored, located or deliberately removed.
9. **Restore goes to Not Assigned.** In Holding Area → Archive → Cleanups, lasso/right-click Restore to Not Assigned. Drag a restored group onto its intended card. This preserves component grouping without silently assigning it back.
10. **Move to Trash is outside Undo.** Right-click/Delete archived or unassigned cleanup to move unused project-owned copies to the operating system's Trash. Shared active files and external originals are protected. SS Undo cannot restore discarded file entries; use OS Trash recovery if needed. The app never silently falls back to irreversible deletion when Trash fails.
11. **Save verifies before skipping unchanged writes.** Changed/missing PNGs and records update; unchanged outputs remain untouched. Up-to-date messages disappear automatically. Artwork review marks changed rows; a cancelled update stays cancelled when closing.
12. **Supervisor checks last.** Save/Refresh first performs ordinary controlled organization. Supervisor then checks identities, connections, expected locations, selected audio, shared records and recovery health. Check project is observational and opens Last check; it does not independently import or rename artwork. Ambiguous cases remain for your decision. Number gaps alone are valid.
13. **Use separate validated backups.** Up to four project-file copies live in the app's backups folder, at most every twenty minutes while changed, plus closing/reorganization checkpoints. Older copies expire after ten days while retaining a valid recovery point. These do not replace the real .StoryboardStudio file or contain every external cleanup file.
14. **Folder naming renames the folder itself.** Registered chapter/archive directory title changes preserve all contents, including unrelated images/subfolders. A collision stops the change rather than merging directories. File naming and Studio Link paths update together. Manually reorganized media should be located/reconnected when not confidently identifiable.
15. **Print exports choose a destination.** PNG Cards/Pages and PDF exports open a picker every time. Managed Cmd/Ctrl+S outputs use the connected project folder and protect cleanups.
16. **Check the recording in Prepare Video → Audio.** Its name and Change… select another audio. External recordings are supported with a red location warning. Locate audio or Recover audio from Subtitler project can restore a missing accessible recording. Choosing different audio requires new timings; originals are not moved or modified.
17. **XML creates a fresh editor assembly.** V1 has storyboards; cleanup components use V2 upward with V1 empty beneath. Source resolution/aspect ratio are retained. Assets larger than the sequence scale down uniformly; smaller ones stay native size. In Resolve select Input Scaling → Center crop with no resizing if its project auto-enlarges small images.
18. **Timeline options are independent.** Split audio at card changes and Chapter markers default off. Markers use the actual ordered chapter/subchapter labels, skipping the first exported chapter. Export without audio bypasses recording-file requirements and keeps existing timings. Without timings, every card uses the adjustable equal duration and the app says so. No option edits the source recording.

**Deferred:** FolderExporter's compact old/new review, excluded-folder audit and stable registration across newly generated PSDs are not part of this patch. No automatic update of already-imported Resolve/Premiere edits is promised. Perform MP4 export remains deferred. Native macOS/Windows UI and receiving-editor behavior still need target-platform validation.
